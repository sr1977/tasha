# Research: Candidate Exercises — Round 2

**Date:** 2026-08-02 · **Depth:** standard · **Constraint:** household kit
(bodyweight / dumbbells / medicine ball), upper/lower/core, no duplicates of
the 27-move pool or the round-1 candidate list.

## Angle

Round 1 covered the staples. Round 2 mines three less-obvious veins the
sources kept surfacing: **unilateral dumbbell work** (bigger core demand,
exposes side-to-side weakness), **medicine ball flow moves** (halos, figure
8s — the ball's unique value beyond slams), and **animal/ground movement**
(bear crawl family — full-body strength with zero kit). Also plugged: rear
delts and spinal erectors, which nothing in the pool or round 1 touches.

## Candidates

### Upper — bodyweight
| Move | Why | Flag |
|---|---|---|
| Supermans | Spinal erectors/rear chain — completely uncovered today | |
| Decline push-ups | Feet on a chair; upper-chest/shoulder bias | needs chair |
| Bear crawl | Shoulders + full-body; crawl a few metres out and back | needs floor space |

### Upper — dumbbells
| Move | Why | Flag |
|---|---|---|
| Floor pullover | Lats without a pull-up bar; works lying on the floor, no bench | |
| Bent-over reverse flyes | Rear delts — nothing in pool or round 1 hits them | |
| Push press | Leg-drive overhead press; the power version of shoulder press | |
| Front raises | Front delt isolation, dead simple station | |

### Upper — medicine ball
| Move | Why | Flag |
|---|---|---|
| Ball halos | Circle the ball around the head; shoulders + core, very low skill | |

### Lower — bodyweight
| Move | Why | Flag |
|---|---|---|
| Curtsy lunges | Third lunge plane (behind-and-across); glute med focus | |
| Broad jumps | Horizontal power; jump out, walk back | needs floor space |
| Donkey kicks | Glute isolation from all-fours; easy roster spread | |

### Lower — dumbbells
| Move | Why | Flag |
|---|---|---|
| Single-leg RDL | Unilateral hinge + balance; the round-2 theme in one move | |
| Farmer's march | March on the spot under heavy load; grip + posture, no walking space needed | |
| Good mornings | Loaded hip hinge variation, hamstring bias | |

### Core — bodyweight
| Move | Why | Flag |
|---|---|---|
| Plank shoulder taps | Anti-rotation plank; noisy-proof and partner-friendly | |
| Bird dogs | Opposite arm/leg control; the quiet discipline move | |
| Reverse crunches | Lower-ab pull without hip-flexor dominance | |

### Core — dumbbells / medicine ball
| Move | Why | Flag |
|---|---|---|
| Dumbbell windmill | Obliques under an overhead load; balance + mobility | keep it light |
| Seated ball figure 8s | Weave the ball over/around the knees; obliques with flow | |
| Ball toe touches | Legs up, crunch the ball to the toes; loads the leg-raise pattern | |

## Notes
- Crab walk and duck walk considered, dropped: awkward in a small station
  footprint and low signal at 3 metres.
- Frog jumps, deep squat hold, weighted twists dropped as near-duplicates of
  pool/round-1 entries.
- Floor pullover chosen over bench pullover deliberately — no bench in the kit.
